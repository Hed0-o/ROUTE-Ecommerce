# UrbanNest

متجر UrbanNest مبني باستخدام Next.js ومتصل بواجهة Route E-commerce API. هويته تجمع بين مستلزمات المنزل والملابس والإلكترونيات.

## التشغيل

1. افتح مجلد المشروع في الطرفية.
2. ثبّت الحزم:

   ```bash
   npm install
   ```

3. شغّل خادم التطوير:

   ```bash
   npm run dev
   ```

4. افتح `http://localhost:3000`.

عنوان الـ API مضبوط في `src/services/api.ts` على `https://ecommerce.routemisr.com/api/v1`.

## الصفحات والوظائف

- الرئيسية: `/`
- المنتجات وتفاصيل المنتج: `/products` و`/products/[id]`
- التصنيفات وتفاصيلها: `/categories` و`/categories/[id]`
- العلامات التجارية وتفاصيلها: `/brands` و`/brands/[id]`
- إنشاء الحساب وتسجيل الدخول: `/register` و`/login`
- استعادة كلمة المرور: `/forgot-password`
- تغيير كلمة المرور بعد تسجيل الدخول: `/change-password`
- المفضلة والسلة والطلبات: `/wishlist` و`/cart` و`/orders`

## خطوات تجربة المتجر

1. افتح `/register` وأنشئ حسابًا باستخدام الاسم والبريد والهاتف وكلمة مرور.
2. سجّل الدخول من `/login`.
3. تصفح `/products` وافتح تفاصيل منتج، ثم تصفح صفحات العلامات التجارية والتصنيفات وتفاصيلها.
4. أضف منتجًا إلى السلة وغيّر كميته أو احذفه، وجرّب إضافة المنتجات إلى `/wishlist` وحذفها.
5. أدخل بيانات التوصيل في السلة واختر الدفع نقدًا أو أونلاين؛ بعد إنشاء الطلب ستجده في `/orders`.
6. جرّب `/forgot-password` لاستعادة كلمة المرور، ثم `/change-password` لتغييرها بعد تسجيل الدخول.

المنتجات والتصنيفات والعلامات التجارية تُحمّل من الـ API. عمليات السلة تستخدم Cart API v2، بينما الحساب والمفضلة والطلبات تستخدم مسارات v1. السلة والمفضلة والطلبات وعمليات الحساب تتطلب تسجيل الدخول. توفر الدفع أونلاين يعتمد على إعداد Stripe لدى خدمة الـ API.
